# Lumi

Nederlandse leerspellen voor groep 1–8 (4–12 jaar). Interactieve spellen, ouderzone, en een Gezin-abonnement.

Live: de productie-URL staat in Vercel onder het project **lumi**.

## Stack

TanStack Start, React 19, Better Auth (e-mail), Neon Postgres.

## Lokaal

```bash
npm install
npm run dev
```

Accounts en voortgang in productie staan in Neon. Zet `DATABASE_URL` en `BETTER_AUTH_SECRET` in de Vercel-projectomgeving.
